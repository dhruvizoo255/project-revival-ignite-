# Project Revival

## Skills
- `project-revival-online-screening/SKILL.md`: Round 1 PPT/repository screening, six published criteria, originality and authenticity checks, ranking, optional SDG bonus.
- `project-revival-challenge-designer/SKILL.md`: Round 2 bespoke feature assignment using the Round 1 handoff, actual active coding time, and one common cohort tier.

## Shared configuration
- `event-rules.md` is the bundle-root configuration.
- Each installable skill also contains its own `references/event-rules.md`. **Keep all three copies identical** when you fill the rules. If installing skills separately, copy the completed rules into each skill's references folder.
- `scoring-and-effort.md`: concise calibration policy.
- `sdg-bonus-guide.md`: optional bonus policy.
- Screening report, batch leaderboard, and challenge brief templates.

## Required before screening
Complete the required event fields: announcement date, N advancing, tie-break order, AI-tool and reuse policies, repo access rules, cure period, and eligibility rules. Confirm the 8-minute inspection time-box or replace it. Calibrate on 3–5 submissions, obtain organizer approval, freeze rule version and rubric, then score the batch.

## SDG and ranking
Base score is 100. Optional SDG bonus is +0 to +2 for SDGs 4, 8, 9, 11, 12, 17. Rank by total /102; ties use the published tie-break order. No SDG claim means no bonus and no penalty.

Official eligibility is undergraduate/postgraduate students across all disciplines. Purely cloned/plagiarized codebases are disqualified when substantiated; shortlisted teams must extend the exact Round 1 codebase and follow their bespoke challenge. Stage 3 uses 60% Custom Feature Implementation / 40% Original Project Depth; judges' and organizers' decisions are final and non-contestable. SDG alignment is encouraged during live defense, not mandatory.

## Round 2
Confirm the active build window after briefing/setup/breaks/testing/demo prep. Select one cohort-wide tier in event rules. Tier A is 1–2 points; Tier B is 2–3 points and only appropriate with at least 4 active coding hours; Tier C is disabled by default. Stage 3 scoring remains with judges.

These skills support organizer decisions; they do not replace organizer approval. Unscorable submissions go to the published clarification/review process rather than being automatically ranked last.
